# Universal Agent Loop

by **Вадим Захаров** · [MIT License](LICENSE)

Одна схема работы для разных проектов и AI-инструментов:
**понять задачу → отдельный инженер → проверка результата → независимый ревьюер
→ исправления по доказанным дефектам → приёмка → короткая память**.

## Что вы получаете

- **Исполняемый runtime** (`agent_loop/`, только стандартная библиотека Python):
  одиночная запись на весь проект, запуск дочерних процессов без shell,
  точный RED→GREEN-забор валидации, закрытие в объявленном порядке,
  freeze-конверт с байтовыми хешами, жёсткая грамматика ревью и приёмка,
  привязанная к конкретному проверенному кандидату.
- **Оффлайн-проверку за одну команду** — без сети, без ключей, без платных
  моделей: `python examples/offline_quickstart.py`
  ([подробности](examples/offline-quickstart.md)).
- **Честные границы**: все гарантии локальные (LOCAL_INTEGRITY), это не
  песочница ОС; ручная приёмка владельцем остаётся значением по умолчанию.
  Точное состояние и ограничения: [docs/STATUS.md](docs/STATUS.md).

## Быстрый старт

Нужен Python 3.10+. Из корня пакета:

```text
python examples/offline_quickstart.py                     # сам runtime в действии
python -I -S -B -m unittest discover -s tests -v          # фокусные регрессии
python -I -S -B reference/smoke.py                        # исторический reference
```

Для подключения к своему проекту читайте [docs/RUNTIME.md](docs/RUNTIME.md)
(контракты и CLI) и [docs/INSTALL.md](docs/INSTALL.md); команды CLI работают
с явным корнем проекта (`python -m agent_loop --project <корень> ...`).

Статус: **исполняемый runtime-кандидат после реального непогодного пилота и
нескольких циклов независимого аудита/ремонта**. Статус конкретного ZIP всегда
определяется внешним audit/release receipt, привязанным к его SHA-256; сам README
не может доказать, что байты уже опубликованы. Точное разделение:
[готовность и ограничения](docs/STATUS.md).

## С чего начать

1. Запустите [оффлайн-быстрый старт](examples/offline-quickstart.md) — он
   показывает настоящий runtime на синтетических ролях за одну команду.
2. Выберите [режим работы](docs/WORKFLOW.md): один инструмент с отдельными
   сессиями, несколько инструментов или честный single-chat fallback.
3. Отдайте агенту [промпт внедрения](prompts/INTEGRATE.md) вместе с этой папкой.
   Он должен сначала проверить ваш проект, сохранить существующие правила и
   предложить минимальное встраивание, а не переписать инфраструктуру.
4. Для обычной задачи достаточно небольшого входного файла и одного task-файла.
   Скилы подключаются по [матрице триггеров](docs/SKILLS.md).
5. Начните с небольшой непогодной задачи и потребуйте настоящий результат проверки.
   [Пример](examples/single-tool.md) показывает разделение контекстов без покупки
   нескольких подписок. [Наша конфигурация](examples/multi-provider.md) — опциональна.
   [Реальный пилот Lineclean](examples/single-tool.md#real-nonweather-pilot-lineclean)
   показывает проверенное внедрение; это не доказательство работы во всех инструментах.

## Запускаемая проверка без моделей

Нужен Python со стандартной библиотекой. Из папки пакета:

```text
python examples/offline_quickstart.py
python -I -S -B -m unittest discover -s tests -v
python -I -S -B reference/smoke.py
```

Первая команда проводит полный цикл runtime на синтетических ролях. Вторая —
фокусные регрессии runtime и review-guard. Третья проверяет reference-контракты
на искусственных данных. Ни одна не запускает AI и не доказывает качество
модели. Проверенные окружение и результаты: [VALIDATION](docs/VALIDATION.md).

## Что экономит ресурсы

Не перечитывать всю историю. Не платить за запуск при неясной задаче.
Не привлекать наблюдателя без необходимости. Проверять командами то, что
проверяется командами. Дорогие модели оставлять для сложных решений и ревью.
Повторять ремонт при новом доказательстве, а не просто с новым номером попытки.

Процент экономии не обещаем: меньше переданных байтов не равно измеренной экономии
токенов или денег. Пилот проверил переносимость, но сравнение затрат ещё не проводилось.
Понятное объяснение с таблицей ролей и примером Sol / Flash / Terra / Luna / Opus:
[как мы выбираем модели и сокращаем лишние вызовы](docs/MODEL_ECONOMY.md).

## Лицензия и происхождение

Пакет распространяется под [MIT](LICENSE), `Copyright (c) 2026 Вадим Захаров`.
Это новое разрешение владельца для данного выпуска, включая сохранённый reference.
Старые поля `NONE` / `WITHHELD` внутри reference описывают момент первоначального
экспорта, а не ограничения этой лицензированной версии: [подробности](docs/PROVENANCE.md).
История и данные исходного проекта не включены. [Релизные проверки](docs/RELEASE.md)
отделяют лицензию от фактической загрузки и проверки опубликованной копии.

Starter — первый выпуск, а не отказ от полной автоматизации. Owner-авторизованная
реализация четырёх рабочих пакетов full-runtime теперь существует в `agent_loop/`
с фокусными регрессиями; каждая возможность остаётся LOCAL_INTEGRITY, требует
независимого ревью и реального пилота, прежде чем называться принятой. История
реестра и сопоставление всех 50 переносимых ID: [реестр переноса](docs/TRANSFER.md).
